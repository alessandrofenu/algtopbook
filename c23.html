Chapter 23

Simplicial sets and quasi-categories

A simplicial set is a combinatorial object that behaves like a space, and the translation is close enough that homotopy theory can be done entirely without topology. This chapter sets up the dictionary and then takes one step past it: weakening a single condition in the definition of a Kan complex produces quasi-categories, in which composition exists but is determined only up to homotopy.

The step is worth taking slowly, because it is where the obstruction-theoretic pattern of Chapter 17 becomes purely combinatorial. Section 23.4 says exactly how.

23.1 Simplicial sets

Definition 23.1. Let Δ\DeltaΔ be the category of nonempty finite ordinals [n]={0<⋯<n}[n]=\{0<\cdots<n\}[n]={0<⋯<n} and order-preserving maps. A simplicial set is a functor X ⁣:Δop→SetX\colon\Delta^{\mathrm{op}}\to\mathbf{Set}X:Δop→Set; we write Xn=X([n])X_n=X([n])Xn​=X([n]), with face maps did_idi​ and degeneracy maps sis_isi​ induced by the injections and surjections of Δ\DeltaΔ.

The representable Δn=Δ(−,[n])\Delta^n=\Delta(-,[n])Δn=Δ(−,[n]) has, by Yoneda, the property that maps Δn→X\Delta^n\to XΔn→X are exactly nnn-simplices of XXX. Two subobjects matter:

∂Δn=⋃idiΔn−1,Λkn=⋃i≠kdiΔn−1,\partial\Delta^n=\bigcup_i d_i\Delta^{n-1},\qquad \Lambda^n_k=\bigcup_{i\ne k}d_i\Delta^{n-1},∂Δn=i⋃​di​Δn−1,Λkn​=i=k⋃​di​Δn−1,

the boundary and the kkk-th horn, the latter being the boundary with one face removed.

Example 23.2. Two constructions from Chapter 20 produce simplicial sets. The singular complex Sing⁡(Y)n=Top(∣Δn∣,Y)\Sing(Y)_n=\mathbf{Top}(|\Delta^n|,Y)Sing(Y)n​=Top(∣Δn∣,Y) of a space, and the nerve N(C)n=Cat([n],C)N(\mathcal{C})_n=\mathbf{Cat}([n],\mathcal{C})N(C)n​=Cat([n],C) of a category, whose nnn-simplices are strings of nnn composable morphisms.

23.2 Kan complexes

Definition 23.3. A simplicial set XXX is a Kan complex if every horn extends: for all 0≤k≤n0\le k\le n0≤k≤n, every map Λkn→X\Lambda^n_k\to XΛkn​→X factors through Δn\Delta^nΔn.

Exercise 23.4 (medium). Show that Sing⁡(Y)\Sing(Y)Sing(Y) is a Kan complex for every space YYY.

Hint. By adjunction, a map Λkn→Sing⁡(Y)\Lambda^n_k\to\Sing(Y)Λkn​→Sing(Y) is a map ∣Λkn∣→Y|\Lambda^n_k|\to Y∣Λkn​∣→Y. Is there a retraction ∣Δn∣→∣Λkn∣|\Delta^n|\to|\Lambda^n_k|∣Δn∣→∣Λkn​∣?

Solution. By Example 20.13 and the adjunction ∣⋅∣⊣Sing⁡|\cdot|\dashv\Sing∣⋅∣⊣Sing, a horn Λkn→Sing⁡(Y)\Lambda^n_k\to\Sing(Y)Λkn​→Sing(Y) corresponds to a map ∣Λkn∣→Y|\Lambda^n_k|\to Y∣Λkn​∣→Y, and a filler corresponds to an extension over ∣Δn∣|\Delta^n|∣Δn∣.

The horn ∣Λkn∣|\Lambda^n_k|∣Λkn​∣ is a deformation retract of the simplex ∣Δn∣|\Delta^n|∣Δn∣ — project from a point placed just outside the missing face, exactly as in the retraction of Exercise 11.2. Composing a retraction ∣Δn∣→∣Λkn∣|\Delta^n|\to |\Lambda^n_k|∣Δn∣→∣Λkn​∣ with the given map extends it. So every horn fills.

Theorem 23.5 (Recalled). Every simplicial group is a Kan complex. The proof is an explicit induction: given a horn, one corrects its faces one at a time using the group operation, each correction leaving the already-matched faces unchanged.

Remark 23.6. Theorem 23.5 is the reason homological algebra is easier than homotopy theory. A simplicial abelian group is automatically fibrant, so no replacement is ever needed; under Dold–Kan such objects correspond to chain complexes, and this is why chain complexes can be manipulated naively while spaces cannot.

The same argument applies to any simplicial object with enough algebraic structure to correct one face at a time, so it applies in particular to the free simplicial module generated by an arbitrary simplicial set — an observation worth carrying out, since that construction is how one passes from a space to its homology in this language.

Example 23.7 (Not everything is Kan). Δ1=N([1])\Delta^1=N([1])Δ1=N([1]) is not a Kan complex. Its 111-simplices are the arrows of the poset 0≤10\le10≤1, and the horn Λ02→Δ1\Lambda^2_0\to\Delta^1Λ02​→Δ1 that assigns the arrow 0→10\to10→1 to one leg and the identity to the other would require a 111-simplex 1→01\to01→0 to fill, which does not exist.

More generally, N(C)N(\mathcal{C})N(C) is a Kan complex if and only if C\mathcal{C}C is a groupoid: filling outer horns is exactly the ability to invert arrows. Fibrancy of a nerve is invertibility.

23.3 Quasi-categories

Example 23.7 isolates the difficulty: outer horns demand inverses, which most categories do not have. Dropping only those conditions leaves something new.

Definition 23.8. A simplicial set XXX is a quasi-category if every inner horn fills: every map Λkn→X\Lambda^n_k\to XΛkn​→X with 0<k<n0<k<n0<k<n extends over Δn\Delta^nΔn.

Example 23.9. Every Kan complex is a quasi-category. Every nerve N(C)N(\mathcal{C})N(C) is a quasi-category: an inner horn Λkn→N(C)\Lambda^n_k\to N(\mathcal{C})Λkn​→N(C) is a string of composable arrows with one composite unspecified, and the composite exists and is unique. So quasi-categories generalise both spaces and categories, which is their point.

Remark 23.10 (Composition, up to homotopy). In a quasi-category the filling of a Λ12\Lambda^2_1Λ12​ horn is a composite: given f ⁣:x→yf\colon x\to yf:x→y and g ⁣:y→zg\colon y\to zg:y→z as 111-simplices, a filler is a 222-simplex whose remaining face hhh is “g∘fg\circ fg∘f”. The filler is not unique, so hhh is determined only up to the relation generated by 222-simplices — a homotopy relation on 111-simplices.

Quotienting by it gives the homotopy category hX\mathrm{h}XhX: objects the vertices, morphisms the homotopy classes of 111-simplices, composition induced by 222-simplices. That composition is well defined and associative is not formal; it requires filling a horn one dimension up, and identifying which horn is instructive — the associativity of three composable arrows is a statement about a 333-simplex.

Exercise 23.11 (easy). Show that the nerve N ⁣:Cat→sSetN\colon\mathbf{Cat}\to\mathbf{sSet}N:Cat→sSet is fully faithful, and that N(C)N(\mathcal{C})N(C) is 222-coskeletal: an nnn-simplex, for n≥3n\ge3n≥3, is uniquely determined by its faces.

Hint. In the nerve, an nnn-simplex records nnn arrows placed end to end. How much of that data is already visible in the 222-skeleton?

Solution. A simplicial map N(C)→N(D)N(\mathcal{C})\to N(\mathcal{D})N(C)→N(D) is determined by its effect on 000- and 111-simplices, i.e. on objects and morphisms, and the compatibility with 222-simplices says exactly that composition is preserved; so NNN is fully faithful.

For coskeletality, an nnn-simplex is a string c0→⋯→cnc_0\to\cdots\to c_nc0​→⋯→cn​, which is determined by its edges ci→ci+1c_{i}\to c_{i+1}ci​→ci+1​, all of which appear in the 111-skeleton; conversely a compatible family of faces of a potential nnn-simplex specifies exactly such a string, and the 222-simplices impose precisely the condition that the composites agree. So for n≥3n\ge3n≥3 no new information is carried.

Exercise 23.12 (easy). Show that h N(C)≅C\mathrm{h}\,N(\mathcal{C})\cong\mathcal{C}hN(C)≅C for every small category C\mathcal{C}C.

Solution. Vertices of N(C)N(\mathcal{C})N(C) are objects of C\mathcal{C}C and 111-simplices are morphisms. Two morphisms are homotopic in the sense of Remark 23.10 when some 222-simplex exhibits one as the composite of the other with an identity — that is, when they are equal. So the morphisms of h N(C)\mathrm{h}\,N(\mathcal{C})hN(C) are the morphisms of C\mathcal{C}C, and composition agrees because a 222-simplex of a nerve is a commuting triangle.

Remark 23.13 (The comparison in general). Exercise 23.12 is one half of a comparison, and the other half is the statement that h\mathrm{h}h and NNN are adjoint, h⊣N\mathrm{h}\dashv Nh⊣N. Setting up that adjunction means producing, for a quasi-category XXX and a category C\mathcal{C}C, a natural bijection between simplicial maps X→NCX\to N\mathcal{C}X→NC and functors hX→C\mathrm{h}X\to\mathcal{C}hX→C. Exercise 23.11 is what makes it tractable: a map into a 222-coskeletal object is determined by its 222-skeleton, so only vertices, edges and triangles are in play, and those are exactly the data out of which hX\mathrm{h}XhX was built.

The trap is to assume the composition in hX\mathrm{h}XhX is associative without producing the 333-simplex that proves it. Anyone constructing the adjunction should say which horn is being filled, and why it is an inner one.

23.4 Filling is obstruction theory

Remark 23.14. Remark 17.17 promised that the pattern of Chapter 17 would reappear here, and this is the place.

In Chapter 17 a map was built over a CW complex skeleton by skeleton; at each stage the obstruction to continuing over an (n+1)(n+1)(n+1)-cell was the class of the composite Sn→Xn→YS^n\to X^n\to YSn→Xn→Y, and the map extended precisely when that class vanished. The obstruction lived in πn(Y)\pi_n(Y)πn​(Y) and was recorded, when nonzero, as a cohomology class.

Here a map is built over a simplicial set simplex by simplex, and the question at each stage is whether a horn Λkn→X\Lambda^n_k\to XΛkn​→X extends over Δn\Delta^nΔn. The structural difference is that no obstruction group appears: the definition of a Kan complex simply demands that every such extension exist, and the definition of a quasi-category demands it for the inner horns.

So the two theories differ in what they do with the obstruction. Obstruction theory measures it; the fibrancy conditions of this chapter abolish it by hypothesis, and the price is that only the objects satisfying the hypothesis may be used. That is exactly the role that “cofibrant” and “fibrant” play in Chapter 22, and it is why replacement is unavoidable there: one has to move to an object where the obstructions vanish.

23.5 Left and right fibrations

Definition 23.15. A map p ⁣:X→Yp\colon X\to Yp:X→Y of simplicial sets is a left fibration if it has the right lifting property against Λkn↪Δn\Lambda^n_k\hookrightarrow\Delta^nΛkn​↪Δn for 0≤k<n0\le k<n0≤k<n, and a right fibration if it has it for 0<k≤n0<k\le n0<k≤n. It is a Kan fibration if it has it for all 0≤k≤n0\le k\le n0≤k≤n.

Warning 23.16 (Handedness is not a convention). The two classes are genuinely different, and no argument transfers from one to the other by symmetry alone: reversing the direction of the simplices exchanges them, but that operation also reverses the direction of every arrow in sight, so a statement about right fibrations becomes a statement about left fibrations over the opposite quasi-category.

The practical consequence is that in any argument one must record which horns are available. An argument that fills Λ0n\Lambda^n_0Λ0n​ is not available for a right fibration, and the commonest error in this area is to use a lifting property that the hypothesis does not supply.

Definition 23.17. A 111-simplex fff of a quasi-category XXX is an isomorphism if its class in hX\mathrm{h}XhX is invertible.

Remark 23.18 (What one-sidedness buys). Isomorphisms admit a lifting characterisation — a 111-simplex is invertible exactly when certain horns involving it can be filled — and that characterisation is what converts the one-sidedness of Definition 23.15 into homotopy-theoretic content. Two statements of that kind are worth knowing: that a right fibration reflects isomorphisms (if p(f)p(f)p(f) is invertible then so is fff), and that an isomorphism in the base with a prescribed lift of its source lifts to an isomorphism upstairs.

Both are proved by choosing the right horn and filling it, and both fail for the opposite handedness, which makes them a good test of Warning 23.16. Anyone working them out should write down, for each filling, which Λkn\Lambda^n_kΛkn​ is being used and check it against Definition 23.15.

23.6 What to carry forward

  • Simplicial sets, horns, and the two fibrancy conditions (Definitions 23.1, 23.3 and 23.8).

  • Sing⁡(Y)\Sing(Y)Sing(Y) is Kan by the same retraction that proved the HEP (Exercise 23.4); simplicial groups are Kan for free (Theorem 23.5 and Remark 23.6).

  • A nerve is Kan exactly for a groupoid, and always a quasi-category (Examples 23.7 and 23.9).

  • Composition in a quasi-category is defined up to homotopy by inner horn filling (Remark 23.10); the nerve is 222-coskeletal (Exercise 23.11).

  • Horn filling is obstruction theory with the obstructions abolished by hypothesis rather than measured (Remark 23.14).

  • Left and right fibrations are not interchangeable; see Warning 23.16 and Remark 23.18.
